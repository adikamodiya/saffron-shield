# Databricks Job Execution Using CLI

## Objective
To execute an existing Databricks Job using Databricks CLI, capture its execution details in JSON format, and store the execution report in a Unity Catalog Volume.

## Step 1: Configure Databricks CLI

Configure the Databricks CLI with the workspace URL and a dedicated profile.

```powershell
databricks configure --host https://dbc-2bd5e4bd-405a.cloud.databricks.com --profile r5_cli
```

Authentication is completed using the requested credentials.

## Step 2: Verify Workspace Access

List the available catalogs to verify that CLI authentication and workspace connectivity are working.

```powershell
databricks catalogs list --profile r5_cli
```

## Step 3: Execute the Existing Databricks Job

Trigger the existing Job using its Job ID and capture the execution response in JSON format.

Job Name: `claims_daily`

Job ID: `1021538314083895`

```powershell
databricks jobs run-now 1021538314083895 --profile r5_cli --output JSON | Out-File "$env:USERPROFILE\r5_cli_temp.json" -Encoding utf8
```

This command triggers the Job and stores its execution response locally in JSON format.

## Step 4: Upload Execution Report to Unity Catalog Volume
 
Copy the generated JSON report into the designated Unity Catalog Volume location.

```powershell
databricks fs cp "$env:USERPROFILE\r5_cli_temp.json" dbfs:/Volumes/claims/raw/landing/cli_check/cli_check.txt --profile r5_cli
```

## Step 5: Verify Job Execution

The execution JSON contains:
- Job ID and Run ID
- Job execution start and end timestamps
- Overall execution status
- Individual task execution statuses
- Task dependencies and execution details
- Run page URLs

## Output Location

Unity Catalog Volume:

`/Volumes/claims/raw/landing/cli_check/cli_check.txt`
